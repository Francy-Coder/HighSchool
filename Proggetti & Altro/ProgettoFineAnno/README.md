# 🛠️ Come eseguire il test

## Prerequisiti

Prima di avviare il programma, assicurarsi di disporre di:

- Il codice sorgente del progetto.
- Tutte le dipendenze necessarie correttamente installate.
- Uno smartphone collegato al computer tramite un cavo USB che supporti il trasferimento dei dati.

## Avvio del programma

Una volta soddisfatti tutti i prerequisiti:

1. Aprire il terminale sul computer.
2. Accedere alla directory contenente il file del progetto.
3. Eseguire il seguente comando:

```bash
python obstacle_detector.py
```
